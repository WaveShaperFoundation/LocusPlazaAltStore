# LocusPlaza AltStore source

Add this source in AltStore Classic (Browse → Sources → +):

```
https://raw.githubusercontent.com/WaveShaperFoundation/LocusPlazaAltStore/main/apps.json
```

IPAs are attached to this repository's releases and `apps.json` is updated automatically by the
release workflow in the (private) app repository. Don't edit `versions` by hand.
